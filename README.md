# Eruditio Excel Training Platform

A comprehensive Excel training platform built with React, TypeScript, and Vite. This application provides interactive Excel training materials, VBA lessons, and practical exercises.

## Getting Started

1. Clone the repository:
   ```sh
   git clone https://github.com/andrekyle/AfrikaTikkunExcel.git
   cd AfrikaTikkunExcel
   ```

2. Install dependencies:
   ```sh
   npm install
   ```

3. Start the development server:
   ```sh
   npm run dev
   ```

4. Open [http://localhost:8080](http://localhost:8080) in your browser.

## Features

- Interactive Excel formula tutorials
- VBA programming lessons
- Hands-on exercises
- Real-world examples
- Responsive design
- Click on "New codespace" to launch a new Codespace environment.
- Edit files directly within the Codespace and commit and push your changes once you're done.

## Can I connect a custom domain to my Lovable project?

Yes, you can!

To connect a domain, navigate to Project > Settings > Domains and click Connect Domain.

Read more here: [Setting up a custom domain](https://docs.lovable.dev/tips-tricks/custom-domain#step-by-step-guide)
