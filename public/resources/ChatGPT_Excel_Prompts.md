# ChatGPT Excel Prompts

Use these prompts with ChatGPT to enhance your Excel productivity!

## Formula Creation

```
Create an Excel formula that [describe what you need]. 
Include an explanation of how the formula works and provide examples with sample data.
```

## Data Analysis

```
I have an Excel dataset with the following columns: [list your columns].
I want to [describe your analysis goal].
What's the best way to analyze this data in Excel?
```

## VBA Coding

```
Write a VBA macro for Excel that [describe functionality].
Include comments explaining each section and how to implement it.
```

## Dashboard Design

```
I'm creating an Excel dashboard for [describe purpose].
I have data about [describe data]. What charts, KPIs, and layouts would you recommend?
Suggest formulas or techniques to make the dashboard dynamic.
```

## Troubleshooting

```
I'm getting [error message] in Excel when I try to [action].
Here's my formula: [paste formula].
What's wrong and how can I fix it?
```

## Learning Path

```
I want to improve my Excel skills for [specific purpose/role].
I currently know [describe skill level].
What's a step-by-step learning path with practice exercises to reach an advanced level?
```

## Best Practices

```
What are the best practices for [specific Excel task] when working with [type of data/industry]?
```

## Optimization

```
My Excel workbook is running slowly. I have [describe size/complexity].
What are the most effective ways to optimize performance?
```

## Integration Ideas

```
How can I integrate Excel with [other tool/service] to automate [specific process]?
```

## Formula Conversion

```
Convert this Excel formula to [DAX/Power Query M/another language]:
[paste formula]
```
